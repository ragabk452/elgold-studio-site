# Al-Yasmina - Behance Copy

## Project Title

Al-Yasmina - Real Estate Brochure

## Subtitle

A real-estate brochure designed for Ecobuild Developments with a premium, readable, sales-focused layout.

## Role

Brochure Design, Editorial Layout, Art Direction

## Tools

Adobe InDesign, Adobe Photoshop, Print Design

## Project Description

Al-Yasmina is a real estate brochure designed to present a project clearly and attractively. The layout combines premium presentation, readable information hierarchy, and strong visual pacing so the brochure works both as a sales tool and a brand asset.

The design direction focuses on clarity, trust, and a refined real estate feel.

## Key Features

- Real estate brochure layout.
- Sales-focused visual hierarchy.
- Premium print design.
- Clear sections and project details.
- Strong image and typography balance.
