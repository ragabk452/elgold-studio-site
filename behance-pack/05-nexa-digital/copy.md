## Project Title

Nexa Digital - Agency Website with Motion

## Subtitle

A modern agency website with bold positioning, smooth motion, service sections, and trust-building content.

## Role

Web Design, Front-end Development, Motion Direction

## Tools / Stack

Responsive Web Design, Motion UI, Landing Page UX, Agency Website

## Project Description

Nexa Digital is a modern agency website designed to communicate credibility fast. The direction combines bold positioning, polished service sections, trust stats, and motion language that makes the brand feel active and confident.

The layout was built to support conversion: clear service messaging, visual rhythm, smooth scrolling, and a direct path toward contacting the agency.

## Key Features

- Agency homepage structure.
- Smooth motion direction.
- Service and trust sections.
- Bold visual positioning.
- Responsive layout.
- Conversion-focused CTAs.
