## Project Title

Anamil Yasin - Arabic E-commerce Store + Dashboard

## Subtitle

A premium Arabic storefront for handcrafted rosaries with product flow, booking/order direction, and a full admin dashboard experience.

## Role

UI/UX Design, Front-end Development, Admin Dashboard

## Tools / Stack

Responsive Web Design, Arabic RTL, Dashboard UI, E-commerce UX

## Project Description

Anamil Yasin is an Arabic-first e-commerce experience built for a handcrafted products brand. The visual direction needed to feel luxurious, warm, and culturally relevant while keeping the user journey simple and conversion-focused.

The project includes a premium storefront direction, product browsing, order/booking logic, deposit flow direction, and a full Arabic admin dashboard experience for managing the business side.

## Key Features

- Arabic-first RTL interface.
- Premium handcrafted brand feeling.
- Product/storefront experience.
- Dashboard/admin direction.
- Booking/order flow.
- Mobile responsive layout.
