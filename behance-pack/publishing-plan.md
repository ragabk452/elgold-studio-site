## Upload Pattern For Every Project

1. Create Project.
2. Upload `cover-behance.jpg` first.
3. Add a text block with the project overview from the project `copy.md`.
4. Upload the numbered images from the `images` folder in order.
5. Add a final text block: "Need a similar project? Contact ELGOLD Studio."
6. Set the cover to `cover-behance.jpg`.
7. Add the tags from `copy.md`.
8. Publish only after preview looks clean.

## Visual Rule

Use one project per Behance post. Do not mix development, branding, and social media into one huge post. Separate projects look more premium and make the profile easier to scan.
