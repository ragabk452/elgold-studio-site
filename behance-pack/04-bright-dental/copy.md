## Project Title

Bright Dental - Clinic Website + Booking Experience

## Subtitle

A calm Arabic clinic website designed around trust, services, doctors, and appointment booking.

## Role

## Tools / Stack

Arabic RTL, Responsive Website, Booking UX, Clinic Website

## Project Description

Bright Dental is a clinic website experience designed to feel calm, trustworthy, and easy to navigate. The site structure helps visitors understand services, review doctors, and move toward booking an appointment without friction.

The design uses a clean medical tone, clear service sections, soft hierarchy, and responsive behavior for mobile users.

## Key Features

- Arabic clinic website.
- Service pages and doctor presentation.
- Appointment booking direction.
- Calm medical UI.
- Trust-focused structure.
- Responsive layout.
