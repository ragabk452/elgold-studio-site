## Project Description

Fast Round is a brand identity project built around a clean visual system and practical brand applications. The identity includes the logo direction, Arabic/English brand usage, color palette, typography, and visual guidelines to keep the brand consistent across touchpoints.

The goal was to create a simple but memorable identity that can work across digital, print, and day-to-day marketing materials.

## Key Features

- Logo system.
- Arabic and English brand presence.
- Color and typography direction.
- Brand guidelines.
- Practical applications.
- Consistent visual language.
