## Project Description

JUN is a premium company profile designed for a real estate and contracting brand. The layout needed to feel polished, credible, and structured, while making company information easy to read and present to clients or partners.

The project focuses on editorial hierarchy, clean spacing, real estate visual language, and a premium print-ready presentation.

## Key Features

- Company profile layout.
- Real estate visual direction.
- Editorial hierarchy.
- Premium print presentation.
- Section structure and readability.
